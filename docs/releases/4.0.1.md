# Eric Task Master 4.0.1

This patch updates the Media Bridge / 媒介桥 destination from `media.npctech.site` to [npcpressbridge.com](https://npcpressbridge.com/) in the bilingual product overview and Dashboard. The approved name stays the same. Task execution, authorization, recovery and browser behavior are unchanged from [4.0.0](https://github.com/npcworkspace-cmyk/eric-task-master/releases/tag/v4.0.0).

The patch ships version-matched runtime packages and driving Skill. Choose one package for your OS/CPU from [v4.0.1](https://github.com/npcworkspace-cmyk/eric-task-master/releases/tag/v4.0.1), plus `SHA256SUMS` and `UNSIGNED-BUILD.txt`. Check the download's SHA-256 before use; native Windows and macOS packages remain unsigned. The separate `eric-task-master-skill-v4.0.1.zip` is instructions and a read-only locator, not the Manager. Import the same-version Skill from that ZIP or from the runtime's `app/skills/eric-task-master/`.

| Target | Native installer | Portable ZIP |
| --- | --- | --- |
| Windows x64 | `eric-task-master-v4.0.1-windows-x64-setup.exe` | `eric-task-master-v4.0.1-windows-x64-portable.zip` |
| macOS arm64 | `eric-task-master-v4.0.1-macos-arm64.pkg` | `eric-task-master-v4.0.1-macos-arm64-portable.zip` |
| macOS x64 | `eric-task-master-v4.0.1-macos-x64.pkg` | `eric-task-master-v4.0.1-macos-x64-portable.zip` |
| Linux x64 | `eric-task-master-v4.0.1-linux-x64.deb` | `eric-task-master-v4.0.1-linux-x64-portable.zip` |
| Linux arm64 | `eric-task-master-v4.0.1-linux-arm64.deb` | `eric-task-master-v4.0.1-linux-arm64-portable.zip` |

The release workflow requires exact-main-SHA five-platform CI and CodeQL success, then publishes the CI-tested package bytes as one immutable Release. A separate read-only verification compares every published asset with those original bytes and the deterministic Skill ZIP. Historical 4.0.0 assets remain unchanged; an existing installation does not upgrade itself. An Owner-authorized idle runtime upgrade and separate Skill import are needed before claiming all three live versions are 4.0.1. See the [installation guide](https://github.com/npcworkspace-cmyk/eric-task-master/blob/v4.0.1/docs/INSTALLERS.md).
