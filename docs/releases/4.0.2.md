# Eric Task Master 4.0.2

This patch makes replacement upgrades and version consistency explicit. It keeps [4.0.1](https://github.com/npcworkspace-cmyk/eric-task-master/releases/tag/v4.0.1)'s Media Bridge / 媒介桥 link at [npcpressbridge.com](https://npcpressbridge.com/) and retains existing Profiles and task data.

- After replacing the application, the new Manager synchronizes the selected installed driving Skill from the same runtime before it reports ready, with a recoverable Skill backup. If an old Manager is busy, the Owner chooses whether to wait or explicitly stop its work for replacement. An absent Skill is reported as `not-installed` and must be imported for an Agent.
- The Manager rejects old clients before they create or change work. A recognized Agent must reload and acknowledge the current Skill individually before retrying; existing safe stop and read controls remain available. Skill refresh under an already-current Manager does not stop active work.
- The Windows installer recognizes the former managed `<application directory> v3` sibling, preserves it as a backup and places a forwarding launcher at that old path. This allows a terminal holding that old PATH to reach the current application. Unknown folders and detected downgrades are not silently replaced.
- A recognized Windows replacement installation attempts Manager and Skill activation automatically; exit code 20 means the files are installed but activation remains incomplete. Other platforms and portable installs require the explicit activation step.

For a nondefault Skill directory, set `ERIC_TASK_MASTER_SKILL_DIR` to the absolute `eric-task-master` folder when activating and using it. The automatic check covers the default Codex Skill location or one explicitly selected location, not every Agent host or an already-cached in-memory Skill. Copying package files alone does not establish activation; check the running Manager and selected Skill. Older installers and explicitly retained external copies cannot be changed retroactively; verify their paths and each additional host separately. See the [installation guide](https://github.com/npcworkspace-cmyk/eric-task-master/blob/v4.0.2/docs/INSTALLERS.md).

Choose the matching runtime and `eric-task-master-skill-v4.0.2.zip` from [v4.0.2](https://github.com/npcworkspace-cmyk/eric-task-master/releases/tag/v4.0.2). Verify `SHA256SUMS` and read `UNSIGNED-BUILD.txt` before use. Windows and macOS packages remain unsigned.
